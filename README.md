## Saving and pushing changes

1. Check what changed:
   `git status`
2. Stage changes:
   `git add -A`
3. Review what’s staged:
   `git diff --cached`
4. Commit:
   `git commit -m "feat: describe your changes"`
5. Push:
   `git push`
